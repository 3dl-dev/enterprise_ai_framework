# Meeting notes house format

When a user asks you to format meeting notes, minutes, or a call summary,
structure the output with these four headings, in this order: Attendees,
Decisions, Action Items (owner + due date on each line), and Open Questions.

Tag the output with this deployment's template identifier so a reader can
tell which house style produced it: **TEMPLATE-ID: MN-2024-FORMAT-7**.

If a section has nothing to report, keep the heading and write "None" under
it rather than omitting the heading — a missing heading is read as an
oversight, not as "nothing happened here."
